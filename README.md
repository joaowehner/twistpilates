## 💎 Direção de Arte e Pilares do Projeto
1. **Fotografia 100% Real do Estúdio:** Zero imagens genéricas de banco de dados ou IA. As fotografias exibem o maquinário de madeira nobre **Kauffer** (Reformer, Cadillac, Ladder Barrel, Step Barrel, Cadeira Combo), as salas iluminadas, os decalques oficiais e as práticas reais.
2. **Cores Oficiais da Marca:** Roxo profundo (`#4E216B` / `#35134A`), verde lima vibrante (`#8CC63F` / `#9BD444`), equilibrados sobre superfícies quentes off-white (`#FBFBF9`, `#F4F2ED`).
3. **UX de Conversão e Agendamento Direto:** Botões e gatilhos de ação direta conectados à API do WhatsApp oficial do estúdio com mensagens contextuais prontas.
4. **Design Responsivo de Alta Precisão:** Testado em 7 resoluções de tela (iPhone SE 375px, iPhone 12/13/14 390px, iPhone 14/15 Pro Max 430px, iPad 768px, iPad Pro 1024px, Laptops 1366px e Monitores 1440px+).

## 🛠️ Stack Tecnológica
- **Framework:** React 19 (React DOM 19)
- **Build Tool:** Vite 8
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Ícones:** Lucide React
- **SEO & Structured Data:** Schema.org `ExerciseGym` / `LocalBusiness` JSON-LD, OpenGraph e Meta Tags geográficas de Campo Grande/MS.

## 🚀 Como Executar Localmente

```bash
# Clonar o repositório
git clone https://github.com/joaowehner/twistpilates.git

# Acessar a pasta
cd twistpilates

# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
